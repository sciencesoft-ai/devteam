# overlay/

Files here are copied over the upstream tree at the same relative path, after
patches are applied. Use this for whole-file replacements: icons, images,
default configs. (This README itself is not copied.)

## Artwork

Every image file under `overlay/` is generated by `scripts/brand_assets.py`
from one geometry (the striped "D" and the agent character), in ScienceSoft
brand colours. Don't edit the generated files by hand: change the script and
re-run it.

```
python -m pip install resvg-py pillow
python scripts/brand_assets.py
```

| Upstream path | What it is |
|---|---|
| `website/electron/icon{,-nightly}.{png,ico,icns}` | Desktop app icon (Windows, macOS, Linux). Nightly builds use the navy tile. |
| `website/electron/build/icons{,-nightly}/*.png` | Linux icon sizes, 16 to 512 |
| `website/electron/trayTemplate{,@2x}.png` | macOS menu-bar icon (black template) |
| `website/public/icon-{192,512}.png` | Browser tab and installed web app |
| `src/kiro_crew/static/kirocrew-logo{,-nightly}.png` | Logo the dashboard serves (`/logo.png`) |
| `packaging/installer-assets/windows-installer-{header,sidebar}.{bmp,svg}` | Windows installer pages |
| `packaging/installer-assets/dmg-background.{svg,tiff}` | macOS disk image window |
| `website/src/assets/avatarPoses/pose-1..11.svg` | Agent and crew avatars. `lib/avatarPoses.ts` parses them: one `<rect fill>`, one body `<path fill="#fff">`, two eye paths without `fill`, eyes centred where its `EYE_CENTERS` table says. |
| `website/src/assets/ghost-poses/pose-1..8.svg` | Chat footer, share card, member profile |
| `website/src/assets/onboarding/kiro-ghost-*.svg` | Welcome tour (the outline file is a mask over the arm drawing) |
| `website/src/assets/kiro-file-chomper.png` | Shown when a file is dragged onto a chat |
| `website/src/assets/product-mark.svg` | The product's nav glyph (patch `0050`; Kiro harnesses keep Kiro's logo) |

The desktop loading screen draws its character inline, so it isn't a file here:
`rewrite_strings.py` swaps it in from `rebrand/loading-character.json`, which
the same script writes.

Masters for documents and slides are in `brand/`: the app icon, the nav mark,
the "DevTeam / ScienceSoft AI" lockup and the character.

Not replaced: built-in apps' own art (Crew Companion, Mochi, Issue Radar and
the app cards under `website/public/app-assets/`), and the logos of other
services (connections, chat channels, agent harnesses), which name those
services correctly.
